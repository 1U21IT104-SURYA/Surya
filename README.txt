Surya Portfolio
---------------
1. Unzip this folder.
2. Double-click index.html to open it in your browser.
3. To host free: upload the folder to Netlify Drop, GitHub Pages or Vercel.

Everything (photo, CSS, JS) is inside index.html. Internet is only needed for Google Fonts.
Change the phone, email or links by searching for them in index.html with any text editor.
